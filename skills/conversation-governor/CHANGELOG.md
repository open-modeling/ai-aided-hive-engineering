# Changelog

## 1.0.0-rc.1 — 2026-10-16

### Changed
- Replaced the earlier ledger-oriented prototype with a stateless communication protocol.
- Established a normative baseline with 13 functional, six language, nine technical, and five verification requirements.
- Added explicit informational/directional classification and in-context ACCEPT/REJECT/DEFER control.

### Added
- Embedded ADS 5.0.0-rc.2 language applicability and meaning rules.
- Bundled communication procedures, portable skill API, and host-hook validation resources.
- Added a test suite for deterministic checks and sample communication scenarios.

### Compatibility
This release candidate changes the lifecycle classification and public behavior of the previous 0.2.0 prototype. It is a new major-line candidate. The previous ledger is not migrated. Existing project records remain unchanged.

### Release qualification
Real-host Codex/Claude Code checks and designated ASD-STE100 Issue 9 review evidence remain release prerequisites.

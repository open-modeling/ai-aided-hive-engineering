# Language and terminology rules

## Language applicability

Use [ASD-STE100 Issue 9](https://www.asd-ste100.org/)
as the external language authority for applicable English prose.

Use the [ADS Language & Meaning Core profile](../standards/ads/language-core/LMC-01_language_standards_profile.md)
to select the applicable ISO, IEC, IEEE, and BCP 14 standards.

Use the [ADS terminology rules](../standards/ads/language-core/LMC-02_terminology_and_meaning_control.md)
and the authorized project terminology.

## Conversation-specific extensions

1. Apply the language profile to Human-Agent and Agent-Agent messages.
2. For other languages, adapt the transferable objectives of the
   English standard to the grammar and conventions of each language.
3. Resolve technical terms from the active project's authorized
   dictionary. Use the [skill dictionary](dictionary.md)
   for communication-specific concepts.
4. Use the [communication rules](communication.md) for message
   classification, direction acceptance, and message structure.
5. Preserve received source material and formal syntax. Put
   agent-authored interpretations in separate text.
6. Report communication-quality findings in the active exchange.

## Conformance evidence

Use [LMC-04](../standards/ads/language-core/LMC-04_language_and_meaning_conformance.md)
for designated formal language reviews.

A formal conformance claim requires evidence from the designated
review process.

When an authoritative resource is unavailable, identify the
resource and report the assessment as partial.

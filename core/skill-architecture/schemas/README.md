# Skill Architecture schema catalog

Suite version: `5.0.0-rc.1`

| File | Contract |
|---|---|
| `ads-common-definitions.schema.json` | Shared skill identity, semantic version, classification, lifecycle, and conformance tokens. |
| `skill-frontmatter.schema.json` | Canonical cross-host `SKILL.md` frontmatter. |
| `skill-api.schema.json` | Skill API identity, applicability, capability, outcome, and communication metadata. |
| `skill-message-envelope.schema.json` | Addressed role-to-skill and skill-to-skill request envelope. |
| `stateful-runtime-envelope.schema.json` | Stateful project-local runtime envelope. |
| `skill-conformance-record.schema.json` | Skill release evidence including reusable Language & Meaning conformance evidence. |
